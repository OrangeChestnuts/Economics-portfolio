> [!summary]+ 概念前言 
> 
> 1. **LM** 代表 [[流動性偏好理論|流動性偏好]]，即貨幣需求 = [[貨幣供給量|貨幣供給]]。它描繪了在「貨幣市場」達到均衡時，利率 ($r$) 與所得 ($Y$) 之間的所有可能組合。
> &nbsp;
> 
> 2. LM 曲線上的均衡，以及曲線外的非均衡狀態 (所得帶動現金交易需求)
> 	1. LM 曲線上的任一點：貨幣市場完全均衡，實質貨幣供給量精準等於實質貨幣需求量（$\frac{M^s}{P}=M^d$）。
> 	   
> 	2. 曲線的左方或上方：商品市場處於超額供給 ($M^s>M^d$)。代表景氣低迷，市場上不需要那麼多現金來進行交易。此時央行發行的流通貨幣量超過了大眾的實際需求。
> 	   
> 	3. 曲線的右方或下方：商品市場處於超額需求 ($M^s<M^d$)。代表目前經濟活動極度熱絡。民眾與企業為了應付龐大的日常買賣，需要保留更多現金在身上（交易動機的貨幣需求 $kY$ 增加）。但在央行貨幣供給總量固定的情況下，市場上的現金立刻變得「供不應求」。

# ㄧ、核心方程式
    
$$\begin{gather}
\textcolor{#F7B32B}{ { \frac{M^s}{P}  } }=\textcolor{#437C51}{ {  L(Y, r) } } \\[1.5em]
\textcolor{#F7B32B}{ { 實質貨幣供給 }  }= \textcolor{#437C51}{ { L_{1}(Y) 交易性與預防性貨幣需求 + L_{2}(r) 投機性貨幣需求 } } \\[1.5em]
\textcolor{#F7B32B}{ { 實質貨幣供給 } } =\textcolor{#437C51}{ { 實質貨幣需求 } } \\[1.5em]
\end{gather}$$

- $M^s$：名目貨幣供給，代表由中央銀行所控制發行的貨幣總數量。
- $P$：物價水準，因此 $\frac{M^s}{P}$​ 代表扣除物價因素後的「實質」貨幣供給。
- $L$：流動性偏好 (貨幣需求)，為 $Y$ 與 $r$ 的函數。
- $Y$：國民所得 / 總產出 (Income)。
- $r$：利率 (Interest rate)。


> [!info|link]+ 相關連結
> - [[流動性偏好理論]]

> [!question] 觀念釐清：為什麼方程式右邊的 $L$ 不用除以 $P$？
> 1. 右邊的 $L$ 已經是透過所得 $Y$ 和利率 $r$ 計算出的「實質」貨幣需求。
> 2. 左邊的 $M^s$ 是央行發行的「名目」貨幣供給，央行能精準控制的只有「帳面上的法定數字」。要再除以物價指數，才能還原成「實質」貨幣供給。

> ~~🔗 關於名目與實質購買力的本質差異，詳見 [[【比較】實質、名目]]。
>
>
> **1. 經濟直覺**：人們沒有「[[貨幣幻覺]]」
> 經濟學假設人是理性的，持有現金是為了它的<font color="#d32f2f">**實質購買力**</font>，而非鈔票上的面額數字。
> - 假設你每天需要買一個便當，便當 $100$ 元時，你會準備 $100$ 元；漲到 $200$ 元時，你會準備 $200$ 元。
> - 無論物價 $P$ 怎麼變，你腦中真正計算的「實質需求」始終是「$1$ 個便當」。
> - 因此，$L(Y, r)$ 在定義的當下，本身就已經是扣除物價影響的**「實質貨幣需求」**了。
> 
> **2. 數學推導：從名目到實質的還原**
> 貨幣市場最原始的均衡，其實是等號兩邊在比拚「名目數量（鈔票面額）」：
> - **名目貨幣供給：** $M^s$ (央行實際發行的鈔票總量)
> - **名目貨幣需求：** $M^d = P \times L(Y, r)$ (物價水準 $\times$ 實質購買力需求)
> 
> 當市場達到均衡 ($M^s = M^d$) 時：
> $$M^s = P \times L(Y, r)$$
> 為了讓等號兩邊都轉化為實質變數，我們將等號兩邊**同除以 $P$**：
> $$\frac{M^s}{P} = \frac{P \times L(Y, r)}{P}$$
> $$\textcolor{#d32f2f}{ \frac{M^s}{P} = L(Y, r) }$$
> 
> 💡 **小結：** 左邊的名目供給除以 $P$ 後變成了「實質貨幣供給」；右邊的名目需求除以 $P$ 後，$P$ 被消掉，剛好還原成純粹的「實質貨幣需求」。兩邊完美對等！~~



> [!tip|brain]+ 經濟直覺
> 在 IS-LM 這種總體經濟模型中，公式裡的 $P$ 嚴格來說比較偏向「GDP 平減指數」。
> 
> 我們可以從公式的對應關係來理解為什麼：
> 
> 1. **$Y$ 的涵蓋範圍：** 模型裡的 $Y$ 代表的是「國民總產出 (GDP)」，裡面包含了民眾的消費、企業的機器設備投資、政府的造橋鋪路等所有項目。
>     
> 2. **CPI (消費者物價指數) 的侷限：** CPI 顧名思義，只衡量了「一般家庭購買的消費品與勞務」的價格。它沒有包含企業買廠房機器的價格，而且還包含了從國外進口的消費品價格。
>     
> 3. **GDP 平減指數的完美對應：** 這個指數衡量的是「國內生產的『所有』最終財貨與勞務」的價格變化。因為它包含了消費、投資與政府支出，剛好能完美對應模型中 $Y$ 的範圍。
>     
> 
> **筆記上的觀念總結：**
> 
> - **在理論與考試上：** $P$ 代表一個抽象的「一般物價水準」。特別注意的是，在目前的「<font color="#d32f2f">修正凱因斯</font> (IS-LM) 模型」階段，我們通常**假設 $R$ 是<font color="#d32f2f">固定不變</font>的（物價僵固）**，所以不會特別去區分它是哪一種指數。等到之後進入「完整凱因斯 (AD-AS) 模型」，物價 $P$ 才會被放開來變動。  
>     
> - **在實務數據上：** 如果要拿現實國家的數據來精確計算實質貨幣供給 ($M^s/P$)，經濟學家會使用 **GDP 平減指數**；但如果只是作大趨勢的粗略估計，用 CPI 來代替也是可以接受的。

# 二、截距與斜率
> [!summary]+ 圖形特徵：
> - **幾何特徵 (正斜率)：** LM 曲線是一條向右上方傾斜的線。
>   <br>
> - **邏輯推導：** 當國民所得 ($Y$) 增加 $\rightarrow$ 交易性、預防性動機提高，需要的現金變多（貨幣需求增加） $\rightarrow$ 在央行貨幣供給量 ($M^s$) 固定的情況下，利率 ($r$) 上升。

為了在圖形上（縱軸為 $r$，橫軸為 $Y$）畫出 LM 曲線，我們將上述方程式具體化為線性函數：$L(Y, r) = kY - hr$，並將公式移項整理成 $r$ 的函數：


> [!example|calculator]+ 舉例計算
> 
> $$\begin{gather}
> \textcolor{#F7B32B}{ { \frac{M^s}{P }} }=\textcolor{#437C51}{ { L(Y,r) } } \\[1.5em]
> \textcolor{#F7B32B}{ { \frac{M^s}{P }} }=\textcolor{#437C51}{ { kY−hr } } \\[1.5em]
> \textcolor{#437C51}{ { hr } }=\textcolor{#437C51}{ { kY } }-\textcolor{#F7B32B}{ { \frac{M^s}{P} } } \\[1.5em]
> r=\frac{k}{h}Y-\frac{M^s}{h\times P} \\[1.5em]
> r=-\frac{M^s}{h\times P}+ \frac{k}{h}Y \\[1.5em]
> r=\textcolor{#316A9E}{ { -\frac{1}{h}\times\frac{M^s}{P} } }+ \textcolor{#B8621B}{ { \frac{k}{h} } }Y
> \end{gather}
> $$

> [!tip|brain]+ 經濟直覺
> 1. 在推導截距與斜率時，用r=……+nY的形式較好，可以直觀看到「截距」是黃色的部分，「斜率」為綠色的部分。
>    (國中數學的$y=ax+b$)
>
> &nbsp;
> 2. 在計算乘數時，用Y=…+nr的形式較好，可以直觀看到「乘數」為前方的係數。
## 1. 截距：由藍色部分決定
- 代表LM 曲線在 Y 軸的起點只和「實質貨幣供給 ($M^s/P$)」與「投機性貨幣需求對利率的敏感度 ($h$)」決定 。
  
- 在 $\textcolor{#316A9E}{ -\frac{1}{h}\times\frac{M^s}{P} }$ 中最前面有負號，$h>0$ 且 $\frac{M^s}{P}​>0$，因此截距是<font color="#d32f2f">負</font>的。

![[LM曲線-20260825-1.jpeg]]


### (1) 幾何意義：LM 曲線是從「地底」鑽出來的
- $Y=0$ 時，數學上 $r=-\frac{1}{h}\cdot \frac{M^s}{P}$​（負利率）。
    
- 但隨著 Y 慢慢增加，整條線會往上爬。直到 Y 增加到某個程度，LM 曲線才會穿越橫軸，正式進入第一象限。
    
- 在教科書上看到的 LM 曲線，其實只是這條直線「浮出水面（進入第一象限）」之後的那一小段。

### (2) 經濟直覺：為什麼 Y=0 時，利率必須是負的？
- 假設今天全國的國民所得 Y=0，代表完全沒有任何商業活動，大家對交易性貨幣的需求 (kY) 是零。

- 此時，央行發行的實質貨幣供給 $\frac{M^s}{P}$ 該怎麼辦？

- 為了解決這筆龐大閒置資金，必須要讓大家願意把這些錢「全部拿去做投機性持有 ($L_s$)」。

- 除非把錢存銀行的利率低到極點（甚至變成負利率，也就是存錢還要倒貼保管費），大家才勉強願意把現金全部塞在床底。這就是為什麼截距在數學上必然為負。

### (3) 考點應用：貨幣政策如何平移 LM 曲線？
這個「負截距」正是用來判斷貨幣政策效果的最佳利器： 
公式：
$$r= -\frac{1}{h}\times\frac{M^s}{P}  +   \frac{k}{h}  Y$$

1. **當央行採取** [[擴張性貨幣政策]]（$M^s$ 變大）：
       
	- 括號內的數值會變成「**更大的負數**」（例如從 −5 變成 −10）。 代表整條 LM 曲線的起始點被往下拉得更深了。
	  
	- 反映在第一象限的圖形上，就是整條 LM 曲線**向右下方平移**。
    
2. **當物價上漲**（$P$ 變大）：
       
	- 分母變大，括號內的負值會「**縮小（向 0 靠近）**」（例如從 −10 變成 −5）。 
	  
	- 這代表 LM 曲線的起始點往上抬了。反映在圖形上，就是 LM 曲線**向左上方平移**。

> [!question]+ 疑難解答
> **Q：** LM曲線的意義到底是什麼？為什麼截距包含h不包含k，可以理解數學推導，但直覺上無法連結。
> **A：** 要直觀理解 LM 曲線的截距，我們必須進入經濟學最愛用的「極端情境思考法」。
> 
> ### 一、 為什麼截距裡沒有 $k$？(當 $Y = 0$ 的廢土世界)
> 在座標圖上，Y 軸的截距代表什麼？代表橫軸等於零，也就是**國民所得 $Y = 0$**。
> 
> **📌 經濟直覺：**
> 想像一個極端的停滯世界，國家完全沒有生產、大家完全沒有收入 ($Y=0$)。
> 這時候，沒有人有錢去買便當、繳房租，所以「交易性與預防性需求 ($kY$)」直接歸零！
> 既然沒有日常交易，大家對所得的敏感度 ($k$) 當然就毫無用武之地了。這就是為什麼截距裡完全沒有 $k$ 的身影，因為在 $Y=0$ 的起點，$k$ 直接失業了。
> 
> ### 二、 為什麼只剩下 $h$ 與 $\frac{M^s}{P}$？
> 既然國家沒有人在買東西，那央行印出來在市面上流通的實質貨幣（$\frac{M^s}{P}$）都跑去哪了？
> 答案是：**必須全部由「投機客（投機性需求）」吞下來。**
>   
> **📌 經濟直覺：**
> 投機客是看利率 ($r$) 吃飯的，也就是取決於對利率的敏感度 ($h$)。
> 因為現在市面上完全沒有日常交易來消耗鈔票，為了讓貨幣市場達到均衡（也就是逼大家把市面上所有的閒錢都留在手上，而不是拿去買債券），市場必須提供一個「極度沒有吸引力的低利率」。
> 
> 低到什麼程度？低到大家覺得：「現在利息這麼爛，買債券根本沒賺頭，我寧願把所有的錢都當成閒錢抱在手上！」
> 
> 這個「逼迫大家抱住所有貨幣的極端利率」，就是公式裡的截距 $-\frac{1}{h}\frac{M^s}{P}$。它反映了在完全沒有實體經濟活動時，單純由「央行發鈔量」與「投機客心理」所決定的**基礎資金成本**。
> 
>   
> 
> ### 三、 截距變大或變小的意義是什麼？
> 在數學上，這個截距是一個負數（$-\frac{1}{h}\frac{M^s}{P}$）。所以當我們說截距「變小」，意思是它變得「更負」，在圖形上就是整個起點**往下掉**。
> 
> **📌 經濟直覺：**
> 假設今天央行實施[[擴張性貨幣政策]]，瘋狂印鈔票（$M^s$ 變大）。
> 
> - **市場現況：** 市面上的鈔票氾濫了。
>     
> - **投機客反應：** 在同樣沒有日常交易 ($Y=0$) 的情況下，央行想要逼投機客吞下這批「額外多出來」的鈔票，原本的低利率已經不夠用了，必須用「更低、更爛的利率」，才能逼大家放棄投資，把這海量的現金全塞進床底下。
>     
> - **圖形結果：** 截距變得更低（起點往下掉）。這會帶動整條 LM 曲線向下（右）平移。
> 
> ### 四、總結
> - **截距的意義：** 它是貨幣市場的「起跑點」。代表在實體經濟完全停擺 ($Y=0$) 時，為了消化掉市場上所有的鈔票，利率必須被壓到多低。
>     
> - **為什麼沒 $k$：** 因為沒人賺錢就沒人花錢消費，交易需求歸零。  
>     
> - **截距下降 (LM 右移)：** 央行大撒幣，市面上的錢變多了，所以起跑點的「資金價格 (利率)」就變得更便宜了。

## 2. 斜率 (正斜率)：由橘色部分決定
- 斜率由 **$\frac{k}{h}$** 決定。
  
  $k$ 代表貨幣需求對<font color="#d32f2f">所得</font>的敏感度，
  $h$ 代表貨幣需求對<font color="#d32f2f">利率</font>的敏感度。
  
- 這兩個參數的比例決定了 LM 曲線有多陡峭。

> [!tip|brain]+ **📝 筆記關聯提示：決定 LM 曲線長相的關鍵** 
> 剛剛推導出 LM 曲線的斜率是 $\frac{k}{h}$。 也就是說，如果 h 很大（大家對利率極度敏感，一點點利息就能逼出大量現金），分母變大，整體斜率 $\frac{k}{h}$​ 就會變小，這時 LM 曲線就會變得**很平坦**！

# 四、LM 曲線的彈性與三大區段

## 1. 核心定義：為什麼彈性只看 $h$
LM 曲線的斜率取決於 $\frac{k}{h}$，斜率同時受到 $k$ 和 $h$ 影響。但因為變數的「穩定性」與「變動範圍」，彈性特徵幾乎完全是由對利率極度敏感的投機動機 $h$ 來決定：

* **交易與預防動機 ($kY$) 是「剛性需求」（缺乏彈性）：**
	為了應付日常買便當或看醫生，必須保留現金。這種需求是被動的，對外在利率環境反應遲鈍。

* **投機動機 ($-hr$) 是「邊際選擇」（極富彈性）：**
	扣除日常開銷後，剩下的閒置資金要在「保留現金」還是「買債券投資」之間做選擇。金融市場資金對利率極度敏感，只要利率微小變動，投資人就會立刻進行鉅額部位轉換。

> [!tip|brain]+  **經濟學的彈性觀念**
> 「彈性」看的是邊際上的變動程度，而非絕對數量的大小。因為 $k$ 幾乎不動，而 $h$ 可以有極端變化，所以討論 LM 曲線的陡峭或平坦，實際上都是在討論 $h$ 的大小。

---
## 2. LM 曲線的三大極端區段
1. 凱因斯極端 (完全平坦)：h→∞（對利率極度敏感）。發生在經濟極度低迷的「流動性陷阱」，大眾預期債券必跌，寧願緊抱所有現金。
   
2. 古典極端 (完全垂直)：h=0（對利率完全不敏感）。人們持有貨幣純粹為了日常交易，毫無投機炒作動機，代表經濟處於充分就業狀態。
   
3. 一般凱因斯區間 (正斜率)：0<h<∞。正常經濟狀態，交易與投機動機皆存在。

# 五、LM 曲線的經濟與政策意涵
LM 曲線的斜率與三大區段，是決定國家總體經濟政策命運的終極指標。它的幾何特徵直接決定了以下兩個核心經濟結果：

## 1. 決定「[[排擠效應]]」的強度
當政府實施擴張性財政政策（帶動所得 Y 增加）時，會引發貨幣市場交易需求上升，進而推升利率。

- LM 越陡峭 (h 極小)：貨幣市場對利率不敏感。微小的資金需求增加就會引發「利率暴衝」。飆高的資金成本會嚴重嚇退民間投資，產生極強的排擠效應。
  
- LM 越平坦 (h 極大)：利率上升幅度微小，民間投資幾乎不受干擾，排擠效應微弱甚至為零。

## 2. 政策大 PK (決定財政與貨幣政策的有效性)
### (1) 處於「流動性陷阱 (平坦 LM)」
- 🔴 貨幣政策無效：利率r 變化很少，就會讓Y變化很大
- 🟢 財政政策超有效：政府大搞建設完全不會引發排擠效應 (Zero Crowding-out)，每一塊錢都能扎實轉化為 GDP。

### (2) 處於「古典區間 (垂直 LM)」
- 🔴 財政政策無效：政府發公債借錢，會引發嚴重的資金排擠，導致利率飆升產生「完全排擠效應 (Full Crowding-out)」，所得 Y 毫無增加。
- 🟢 貨幣政策超有效：央行一增加貨幣，民眾不需要多餘閒置現金，會立刻拿去消費投資，直接帶動實體經濟。

### (3) 處於「一般區間 (正斜率 LM)」
- 財政與貨幣政策皆有一定效果。擴張性財政政策會推升部分利率，產生「部分的排擠效應」。
- 💡 政策選擇的終極指南 (央行總裁必修課)
	預判經濟體處於哪一個 LM 區段，決定了救援經濟該由「財政部撒錢」還是「央行印鈔」。
