# 三、IS曲線的彈性
IS 曲線的彈性（也就是這條線到底「有多平」或「有多陡」）不僅僅是圖形上的變化，它更是**政府與央行在決定要使用「財政政策」還是「貨幣政策」時，最關鍵的判斷依據。**

## 一、定義
我們可以把 IS 曲線的彈性，理解為「商品市場對利率變化的敏感程度」。這主要取決於你前面筆記裡寫到的參數 $b$（投資對利率的敏感度），以及乘數的大小。

## 二、當 IS 曲線「很平坦」（富有彈性）

- **經濟直覺**：代表企業對利率的變化**非常敏感**（$b$ 很大）。只要央行稍微降息一點點，企業就會瘋狂借錢蓋廠房，讓投資 ($I$) 大爆發。
    
- **政策大PK**：
    
    - 🟢 **貨幣政策超有效**：央行只要稍微增加一點貨幣供給，讓利率降一點點，就能引發巨大的投資熱潮，讓國民所得 ($Y$) 大幅增加。
        
    - 🔴 **財政政策效果差（排擠效應大）**：如果政府此時選擇自己花錢（擴張性財政政策，如造橋鋪路），會導致市場對資金需求增加，推升利率。因為民間企業對利率很敏感，利率一升，民間投資就會大幅縮手。政府花錢創造的產出，剛好被民間縮手的投資抵銷掉，這在經濟學上稱為嚴重的「排擠效應 (Crowding-out Effect)」。
        

## 三、當 IS 曲線「很陡峭」（缺乏彈性）

- **經濟直覺**：代表企業對利率的變化**超級無感**（$b$ 很小）。不管利率怎麼降，企業就是不想借錢投資（可能是因為對未來景氣極度悲觀）。
    
- **政策大PK**：
    
    - 🔴 **貨幣政策失效**：央行就算把利率降到接近 0（例如陷入流動性陷阱），企業還是不願投資，國民所得 ($Y$) 根本推不動。貨幣政策形同廢鐵。
        
    - 🟢 **財政政策超有效**：既然民間不投資，那就換政府來花錢！政府擴大支出推升國民所得，雖然這也會帶動利率上升，但因為民間企業本來就對利率「無感」，所以不會有什麼投資被排擠掉。政府投入的每一分錢，都能扎實地轉化為國民所得的成長。
        

### 💡 總結：政策選擇的終極指南

為了解決經濟衰退，官員們必須先判斷現在的 IS 曲線長怎樣，才能對症下藥：

|**IS 曲線形狀**|**企業對利率的態度**|**誰來救經濟最有效？**|**經濟學派主張**|
|---|---|---|---|
|**平坦 (高彈性)**|非常敏感|**央行 (貨幣政策)**|貨幣學派|
|**陡峭 (低彈性)**|非常遲鈍 / 無感|**政府 (財政政策)**|凱因斯學派|

所以，學會看 IS 曲線的彈性，就等於擁有了判斷「國家現在該印鈔票降息，還是該舉債造橋鋪路」的上帝視角！
